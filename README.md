# MuchUp – AI がアイスブレイクするリアルタイムグループチャット

MuchUp は、**AI がアイスブレイクを担い、人間がコミュニケーションに集中できる場をつくる**リアルタイムグループチャットアプリケーションです。

共通の趣味・プロフィール・好きなものをもとにユーザーをマッチングし、初対面の人同士が自然に会話を始められるようにします。  
AI は会話の主役ではなく、司会者・ファシリテーターとして話題提供、深掘り質問、ミッション提示を行い、場の空気を温めます。


> AIがアイスブレイクに集中する、人間がコミュニケーションに集中する。

---

## Why MuchUp?

初対面の人同士が会話を始めるとき、最初の話題づくりや沈黙の気まずさは大きなハードルになります。

特に、ランダムマッチング、オンラインコミュニティ、ハッカソン、新卒研修、チームオンボーディングのような場では、参加者同士が自然に話し始めるまでに時間がかかります。

MuchUp は、その「最初の一歩」を AI が支援します。

AI が会話のきっかけを作り、人間は自分の好きなことを話し、相手の話を聞き、自然なコミュニケーションに集中できます。

## Concept

MuchUp のコンセプトは、AI と人間の役割を明確に分けることです。

### AI の役割

- 最初の話題を出す
- 会話の司会をする
- 共通点を引き出す
- 深掘り質問をする
- ミッションを提示する
- 会話が止まったときに流れを作る
- 初対面の緊張感を下げる

### 人間の役割

- 自分の好きなことを話す
- 相手の話を聞く
- 自然にリアクションする
- 共通点を見つける
- 人間同士の関係性を作る

MuchUp は、AI と会話するためのアプリではありません。  
AI が人間同士の会話を支援するためのアプリです。

---

## Use Cases

### 1. ランダムマッチング

ユーザーはプロフィールや趣味を登録し、共通点のあるユーザーとランダムにマッチングされます。  
マッチング後は Room に入り、初対面の相手とリアルタイムに会話します。

AI は Room 内で司会者として振る舞い、会話が自然に始まるようにサポートします。

例:

```text
AI: まずは最近ハマっていることを1人ずつ話してみましょう。

User A: 最近はカフェ巡りにハマっています。

AI: いいですね。どんな雰囲気のカフェが好きですか？
```

### 2. チームオンボーディング

企業の新卒研修、インターン、ハッカソン、新しく組まれたチームなど、初対面のメンバー同士が打ち解ける場でも利用できます。

AI がアイスブレイクを進行することで、参加者は司会や話題づくりを気にせず、会話そのものに集中できます。

想定利用例:

- 新入社員同士のオンボーディング
- インターンチームのアイスブレイク
- ハッカソンチームの初回顔合わせ
- オンライン研修でのグループ交流
- コミュニティイベントでの交流促進

## 全体アーキテクチャ

```text
               ┌──────────────┐
               │   Frontend   │
               │     Web      │
               └─────┬────────┘
                     │ REST / WebSocket
                     ▼
        ┌─────────────────────┐        ┌─────────────────┐
        │   Envoy Gateway     │◀──────▶│  Auth Service    │
        │  - Auth / Session   │  gRPC  │  - Login/Auth    │
        │  - Rate Limit       │        │  - JWT / Session │
        │  - HTTP → WebSocket │        │  - Token Verify  │
        │  - HTTP → gRPC      │        │  - User Context  │
        │  - TLS Termination  │        └─────────────────┘
        └─────┬───────────────┘
              │ gRPC / WebSocket
              ▼

┌───────────────┐        ┌─────────────┐
│ API Service   │        │ AI Service  │
│ - Business    │  gRPC  │ - AI / ML   │
│ - WebSocket   │──────▶ │ - gRPC 　　 │
│ - Redis client│        │             │
└───────┬───────┘        └─────────────┘
        │
        ▼
┌───────────────┐
│ Redis         │
│ - Hash        │
│ - Streams     │
└───────┬───────┘
        │
        ▼
┌───────────────┐
│ DB            │
└───────────────┘
```

- redis だけに room の状態を持たせる（単一 trust）
- envoy で gateway を定義してそこでリクエストをすべて認可・認証する。ビジネスロジックは外部を気にしない
